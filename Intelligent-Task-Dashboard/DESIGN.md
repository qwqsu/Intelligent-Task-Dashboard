# Dayflow 视觉与交互说明

Dayflow 是面向年轻规划者的个人任务工作区。界面重点是让用户快速读懂今天、马上开始下一步，而不是堆叠装饰性组件。视觉上采用纸张底色、深墨色导航、苔绿色主色和珊瑚色提醒，保留一点活泼感，但不使用渐变按钮、毛玻璃或满屏大圆角卡片。

## 视觉原则

- **先读信息，再看装饰**：页面标题、今天的节奏、任务状态和下一步操作拥有明确层级。
- **平面、克制、有温度**：使用实色背景、细边框和轻阴影；卡片只用于分组，不把每一行信息都包成独立面板。
- **动作有颜色，内容少噪音**：苔绿负责主要行动与进行中状态，珊瑚色负责逾期和需要注意的事项，黄绿色用于完成度和积极反馈。
- **支持短时间规划**：任务页提供搜索、优先级、排序、今天和逾期范围；日程页提供回到今天和选中日期的上下文。

## 色彩

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| Paper | `#f5f3ee` | 页面背景 |
| Surface | `#fffefa` | 内容表面 |
| Ink | `#17211f` | 主文字与侧栏 |
| Moss | `#2f5d50` | 主要操作、进行中 |
| Lime | `#d8ee77` | 完成度、积极反馈 |
| Coral | `#e8725c` | 逾期、警示 |
| Amber | `#d49a2a` | 提醒、日程标记 |

主题切换通过 CSS 变量覆盖颜色，不改变信息结构。暗色主题保留同样的对比关系，避免仅靠颜色传达状态。

## 布局与组件

- 桌面端使用深色侧栏 + 内容工作区；移动端切换为顶部标题和底部导航。
- 页面内容最大宽度为 `1440px`，默认间距为 `24px`，紧凑布局会缩小内容间距以提升信息密度。
- 卡片圆角以 `6px` 和 `10px` 为主，按钮和标签不使用超大圆角。
- 任务行通过左侧优先级色条识别重点，状态使用文字和图标共同表达。
- 图表使用低饱和苔绿、珊瑚、黄绿色和蓝色，减少视觉噪音并保持和主界面一致。

## 交互约定

- 新建任务和日程都必须通过表单校验；日程结束时间必须晚于开始时间。
- “今天”和“逾期”是任务页的一等筛选条件，仪表盘可以直接进入今日清单。
- 日历按本地日期计算今天、事件和逾期，避免 UTC 偏移导致跨日显示错误。
- 网络服务不可用时保留本地任务/日程，并给天气模块提供可操作的离线提示。
- 已完成任务记录 `completedAt`，复盘页按实际完成时间计算趋势。

## 响应式断点

- `> 1024px`：侧栏常驻，仪表盘使用多列布局。
- `761px - 1024px`：内容列数减少，保留侧栏。
- `<= 760px`：单列内容、底部导航、工具栏换行，保证触控目标可用。
